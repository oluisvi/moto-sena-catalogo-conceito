# Moto Sena — conceito de catálogo digital

Protótipo estático de catálogo com três direções visuais, busca, filtros, comparação, favoritos e seleção para consulta pelo WhatsApp.

Fotos e informações dos produtos foram transcritas do catálogo compartilhado pela Moto Sena. Preços e disponibilidade aparecem sob consulta e devem ser confirmados com a loja.

Este é um conceito demonstrativo; não processa pagamentos nem confirma estoque.
